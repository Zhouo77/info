项目展示

总泰珠宝海外官网电商平台 （zongtaigem.com）

2026.07 - 2026.09 | 全栈开发

项目描述:

面向珠宝行业的“一对一问价制”B2B海外电商平台，构建“顾客提交询价 →顾问线下跟进 →后台登记出货”的成交闭环，包含前台商城与运营管理后台两套系统，已在 zongtaigem.com上线运行。

项目内容：

Java 17 Spring Boot 3.3 Vue3 MyBatis-Plus PostgreSQL 16 Spring Security 6 JWT Caffeine Vite Pinia TailwindCSS Docker Compose Nginx

全栈开发与交付：

前台商城（商品列表展示、收藏、询价清单、账号体系）与运营管理后台（商品管理、分类、库存、出货、询盘、访客、系统配置），共 17 个 Controller / 90 个REST 接口 / 20张数据表，后端约 1.4 万行 Java、前端48 个 Vue 组件；

库存与出货联动：

库存以单一字段承载可卖数量，出货登记是唯一扣减来源（增删改自动回补差额），已出货量按出货流水实时推算而非冗余存储；结合 MyBatis-Plus乐观锁拦截并发超卖，并为每次库存变动留存变更前后快照与增减量的审计流水;

鉴权与会话管理：

基于 Spring Security 6 + JWT 实现无状态双角色鉴权，并实现登录设备会话机制：管理员最多 2 台、顾客 1台同时在线，超限登录自动顶掉最早会话、旧 token立即失效；配合登录限流、SHA-256 哈希存储；

部署与工程规范：

Docker Compose 编排数据库 / 后端 / Nginx 三容器，Nginx 配置HTTPS、gzip 与静态资源缓存；为后端 16 个 Service 编写 339个单元测试用例并输出测试报告、性能优化报告、边界值测试报告与平台使用手册。
